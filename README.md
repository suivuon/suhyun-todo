## 실행 및 검증

배포 디렉터리는 `dist/`입니다. 빌드나 패키지 설치 없이 정적 서버에서 사용할 수 있습니다.

```sh
node --check dist/app.mjs
node --check dist/model.mjs
node --test tests/model.test.mjs
```

## 데이터

- IndexedDB `suhyun-todo`, `data` store에 저장됩니다.
- 서버로 일기나 사진을 전송하지 않습니다. 기기·브라우저 간 동기화는 없습니다.
- 백업·복원 메뉴는 모든 할 일, 날짜 기록, 계획·실제 기록, 글, 카드, 사진을 JSON 파일로 옮깁니다.
- 여러 탭에서 동시에 수정한 경우 이전 탭이 최신 저장을 덮어쓰지 않도록 revision을 검사합니다.
- 사진은 긴 변 1600px 이하의 JPEG로 저장됩니다.

## 주요 동작

- `/`: 제목만 입력해 오늘(한국 시간) 할 일에 추가. 다른 날짜를 보고 있어도 실제 오늘 날짜로 등록됩니다. 상단 `+ 할 일`은 Inbox에 추가합니다. 날짜·카테고리별 인라인 입력은 해당 화면의 맥락을 적용합니다.
- 할 일 행에 초점을 둔 상태의 Tab / Shift+Tab: 들여쓰기·내어쓰기.
- 상태 □ → △ → ✓. △는 다음 날 이어 할 일을 한 번 생성하고 시간은 비워 둡니다. 같은 날 ✓로 바꾸면 자동 이어 할 일을 취소합니다.
- 부모 상태는 수동으로 지정하며 회고 개수는 상위 할 일 기준입니다.
- 전체 미루기는 원래 날짜의 PLAN을 보존합니다. 고정 약속 포함 여부는 확인창에서 선택합니다.
- 할 일을 PLAN으로 끌어 배치. 블록을 끌어 이동하거나 아래 손잡이로 길이 조절. 빈 칸 더블클릭으로 등록 가능합니다.
- ACTUAL의 빈 시간대를 클릭해 끌어 직접 기록. PLAN 가져오기는 독립적인 ACTUAL 블록을 만듭니다.
- 일기 카드에는 삽입 당시 제목·카테고리·시간·상태를 복사하며 이후 원본 수정이 반영되지 않습니다.
